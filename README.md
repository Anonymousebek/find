# FIND (Find Is Not Depot)

FIND is a Ruby based marketplace application. It builds upon the concepts of
the "Depot" application from Agile Web Development with Rails, but operates
as a distinct, independent project.

## Prerequisites

* Ruby (v4.0.5+)
* Ruby on Rails (v8.1+)
* Bundler
* SQLite3

## Installation

1. `git clone https://github.com/anonymousebek/find.git`
2. `cd find`
3. `bundle install`
4. `rails db:setup`

## Usage

1. `rails server`
2. Navigate to `http://localhost:3000`

## Testing

`rails test`
